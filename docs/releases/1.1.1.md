# eng 1.1.1

## Changes

- `security.osv_lockfile` lets PolyCore scan its workspace `Cargo.lock` instead of historical
  nested `vendor/*/Cargo.lock` files.
- ADAMANT now records the merged Polykrom controls (#281), the open MCP quality (#282) and
  security/advisory (#287) PRs, and the PolyCore controls PR (#28).

## Verification

- Full kit gate and security scans pass.
- The site artifact and this release use the same `eng-kit.zip` digest.
- No product behavior changed.

## Limits

This is a kit/infrastructure release. It does not release Polykrom or PolyCore: their gates and
benchmarks are still open.
