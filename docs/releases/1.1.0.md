# eng 1.1.0

This release makes the kit usable as a live handbook and adds the missing release-performance
gate.

## Highlights

- **ADAMANT** at <https://adamant.cc>: the generated portal, `agents.json`, `llms.txt`, the
  skill explorer, build paths, tool catalog, evidence model and downloadable kit.
- **`eng perf-check`**: compare measured metrics with an accepted baseline; higher-is-better
  and lower-is-better metrics, with a configurable regression tolerance.
- **`eng release-check`** now requires the performance comparison in addition to clean HEAD,
  full evidence for that HEAD, version, changelog, notes, rollback and artifact hashes.
- **Pinned actions and action auditing**: `eng audit-actions` rejects mutable refs; the kit and
  pilot CI use full commit SHAs.
- **Node 24 action releases** remove the Node 20 deprecation warning.
- **Expanded SAST**: `os.system`, `pickle.loads` and `execSync` rules, each with fixtures.

## Verification

- Kit CI: `make check` — 48 tests, 9/9 control checks, agent harness 2/2 and no-op 0/2.
- Site: deployed with Wrangler to Cloudflare Workers; `https://adamant.cc` returns 200.
- Release gate: full evidence, artifact hash and performance comparison recorded.

## Limits

A green release gate covers the checks that ran. It is not a proof of correctness or security.
Impact analysis remains textual; the kit does not generate SBOMs or signatures; OSV needs a
supported lockfile and network.
