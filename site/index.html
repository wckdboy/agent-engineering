01 — The loop

Understand. Plan. Prove.

Six phases, one rule: a skipped or blocked check is never a pass. The loop is deliberately small enough to run on every change.

06 — Evidence

A record, not a vibe.

Every verification writes one hash-chained record: exact commands, exit codes, durations, output hashes, Git state, config hash and scanner versions.

pass
Ran and succeeded

Every required command exited 0; required scanners completed with no findings.

fail
Ran and failed

A required command, timeout or security finding. The failing log stays with the record.

blocked
Gate unknown

A required scanner or config is missing. Blocked is not a pass and never becomes one.

skipped
Not applicable or absent

Reported as unverified. Optional scanner absence is visible, not silent.

error
Untrustworthy result

The tool ran but did not produce a report. Treated as unknown, not green.
